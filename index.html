Accessible websites, one script tag away

EquAlly is a lightweight accessibility widget you drop into any site. It adds a floating button that lets visitors turn on high contrast, a dyslexia-friendly font, larger text, reduced motion, and more — without you touching your site's design.

<script src="equally.js"></script>

Feature: Navigation mode

Jump between links, buttons & headings

Turn on "Navigation mode" in the widget menu, then use the arrow keys (or Tab / Shift+Tab) to step through every link, button, and heading on the page. A blue outline tracks the current stop, and screen readers hear an announcement for each one — try it on the sample link and button below.

Feature: Language auto-detect

Page language

The widget's own menu has an EN/DE switch, but it also auto-detects from this page's declared language on first visit. These links set <html lang> so you can test that default (a language picked manually in the widget menu is remembered and takes priority after that).
